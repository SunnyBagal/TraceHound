**Verdict.** The held-out run can produce an honest, small result, and the plan should protect that rather than chase a win. With 20 bugs, one run and Nemotron only, "TraceHound beats CodeRabbit and Greptile" is reachable only if the true gap is about 30 recall points, which nothing measured suggests. The strongest claim we can expect to defend is: an open-model reviewer at about $0.08 per PR that catches as many later-fixed bugs as two commercial tools within the precision of the test, with a stated comment count per PR, plus the earlier public-benchmark result (tied with Cursor and Greptile, ahead of CodeRabbit and Copilot, behind Augment). Three things can still move the number before the freeze, in order of evidence: choosing the configuration under the new metric, recovering empty replies, and getting references into the context. Each has a gate fixed below. Everything else is harness work so that the single run cannot be voided or disputed.

### 1b. Is 20 bugs enough, and for what claim?
- **One tool's recall:** at 10 of 20 the 95% Wilson interval is 30–70%; at 5 of 20 it is 11–47%. The set gives a rough level, not a rank.
- **Two tools, paired on the same 20 cases (exact sign test):** p < 0.05 needs discordant cases of 6–0, 8–1 or 10–2. 5–0 gives 0.063 and 7–1 gives 0.070. So only gaps of about 30 recall points can be called.
- **Expected level (guess):** later-fixed bugs are ones human reviewers missed, so recall should be far below the old benchmark's 47%. The seeded test caught 9 of 22 (brain `NOW.md`, 28 Oct). A plausible outcome is 2–6 of 20 for every tool, where no pair can be separated.
- **F is the wrong headline here.** Each bug case has one golden and clean cases have none, so F mostly measures how many comments a tool posts. Precision is only a lower bound (budget.md:106-110).
- **Claim it can support:** "On 29 fresh PRs from four TypeScript repos (20 with a bug that a later merged fix repaired), TraceHound commented on X of 20, CodeRabbit on Y, Greptile on Z (matches proposed by two judges, confirmed blind by hand). Differences of fewer than about 6 bugs are not distinguishable at this size. TraceHound posted C comments per PR at $D per PR."
- **Claims it cannot support:** a rank, "beats" or "matches" (equivalence needs far more cases), true precision, anything about Augment, Cursor or Copilot, or about other languages.
- **Dev can add a second table.** 31 dev bugs with a CodeRabbit row (free) give a selection-set table, labelled as such, like the all-50 table. Greptile has no dev row (credits).
